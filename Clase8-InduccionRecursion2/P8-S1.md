## a.
para todo xs. para todo ys. 
`length (xs ++ ys) = length xs + length ys`

Sean xs' e ys', voy a demostrar usando inducción sobre la estructura de xs'.

Caso base) xs' = []
¿ `length ([] ++ ys) = length [] + length ys` ?

Caso ind.) xs' = x:xs
HI) ¡ `length (xs ++ ys) = length xs + length ys` !
TI) ¿ `length ((x:xs) ++ ys) = length (x:xs) + length ys` ?

caso base)

¿ `length ([] ++ ys) = length [] + length ys` ?

Lado derecho
```
    length ([] ++ ys)
=                   def. ++.1
    length ys
```

lado izquierdo
```
    length [] + length ys
=                       length.1
    0 + length ys
=                       aritm.
    length ys
```


Caso inductivo)
¿ `length ((x:xs) ++ ys) = length (x:xs) + length ys` ?

lado izquierdo
```
    length ((x:xs) ++ ys)
=                       (++).2
    length (x:(xs ++ ys))
=                       length.2
    1 + length (xs ++ ys)
```

lado derecho
```
    length (x:xs) + length ys
=                       length.2
    1 + length xs + length ys
=                       HI
    1 + length (xs ++ ys)
```

## b.
para todo xs. para todo ys. para todo zs.
(xs ++ ys) ++ zs = xs ++ (ys ++ zs)

_¿Dónde debería hacer recursión?_ _¿Solo xs, o xs e ys?_
_probamos con xs_

Sean xs', ys' y zs' listas cualquiera, voy a demostrar por inducción sobre la estructura de xs'

Caso base) xs' = []

([] ++ ys) ++ zs = [] ++ (ys ++ zs)

Caso inductivo) xs' = x:xs
HI) (xs ++ ys) ++ zs = xs ++ (ys ++ zs)
TI) ((x:xs) ++ ys) ++ zs = (x:xs) ++ (ys ++ zs)

Caso base)

```
    ([] ++ ys) ++ zs = [] ++ (ys ++ zs)
=                       (++).1
    ys ++ zs = ys ++ zs
```

Caso inductivo)

Lado izquierdo
```
    ((x:xs) ++ ys) ++ zs 
=                       (++).2, xs <- (x:xs), ys <- ys
    (x:(xs++ys)) ++ zs 
=                       (++).2, xs <- (x:(xs++ys)), ys <- zs
    x:((xs ++ ys) ++ zs)
```

```
    (x:xs) ++ (ys ++ zs)
=                       (++).2, xs <- (x:xs), ys <- ys ++ zs

    x:((xs ++ ys) ++ zs)

## d.
elem = any . (==)

Por ppio de extensionalidad, para todo `e::a`, `xs:: [a]`

¿ elem e xs = any . (==) e xs ?

Sea e' un elemento de tipo a cualquiera, sea xs' una lista de tipo lista de a cualquiera

¿ elem e' xs' = any . (==) e' xs' ?

Por ppio de induccion sobre la estructura de xs',

Caso base) xs' = []
`elem e' [] = any . (==) e' []`

Caso inductivo) xs' = x:xs
HI) elem e xs = any . (==) e xs
TI) elem e' (x:xs) = any . (==) e' (x:xs) 

caso base)

Lado izquierdo
```
    elem e' []
=           elem.1
    False
```

lado derecho
```
    any . (==) e' []
=               (.)
    any ((==) e') []
=               any.1
    False
```

Caso inductivo

lado izquierdo
```
    elem e' (x:xs)
=           elem.2
    e' == x || elem e' xs
=               HI
    e' == x || any . (==) e' xs
=               (.)
    e' == x || any ((==) e') xs
```

```
    any . (==) e' (x:xs)
