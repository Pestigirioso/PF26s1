## Ejercicio 2
Forma esquemática de una función por recursión sobre los tipos anteriores

```haskell
-- Planilla
f Fin = ...
f (Registro n p) = ... n ... f p ...

-- Equipo
g (Becario n) = ... n ...
g (Investigador n e1 e2 e3) = ... n ... g e1 ... g e2 ... g e3 ...
```
